Support

Help with Sonora.

Install it, set up your library and fix the common problems.

Install

Install in three steps.

Download the APK

Open the download page on your phone and get the latest APK. Most phones need arm64-v8a.

Allow the install

Android asks before it installs an app from your browser or file manager. Allow it for this one install. In Settings, look for "Install unknown apps". The name varies by phone maker.

Open Sonora

Follow the first-run steps. Allow access to audio and notifications, then choose your music folder.

Go to the download page

Library

Set up your music.

Choose the folder your music lives in. Sonora scans it once. Added new songs? Pull down on a library tab, or tap Sync Now in Settings.

  • Formats: MP3, M4A, AAC, FLAC, OGG, Opus, WAV and more.
  • Lyrics: put a .lrc or .txt file with the same name next to the song.
  • Artwork: Sonora reads embedded cover art, and cover.jpg or artist.jpg files in the folder.

Questions

Common problems.

Some songs are missing.

Tap Sync Now in Settings. Check that the songs are inside the folder you chose, and that the file type is supported.

Lyrics do not show up.

The lyrics file needs the same name as the song, for example "Ember.lrc" next to "Ember.mp3". Then sync again.

Music stops when I leave the app.

Playback should continue in the background, with controls in the notification. Some phones stop background apps to save battery. Allow Sonora to run in the background in your phone settings.

How do I update Sonora?

The app can check GitHub for new releases and suggests the right APK for your phone. You can also install the newest APK from the download page over the old version.

Does it work with Android Auto?

Yes. You can browse songs, albums, artists and playlists from the car display.

I found a bug.

Please open an issue on GitHub, or send us a message from the contact page.

Still stuck? Tell us.

Send a message and we reply as soon as we can.
