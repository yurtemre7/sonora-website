iPhone

iPhone で使う Sonora。

Sonora は App Store にはありません。各リリースには署名なしの IPA が含まれていて、サイドロードツールでインストールします。iOS では音楽の置き場所も少し違い、アプリ専用のフォルダに入れます。

IPA を入手音楽の追加

ご注意: iOS 版は新しいものです。これまでは iOS シミュレーターでのみ検証しており、実機の iPhone ではまだ試していません。iOS 15 以降が必要です。不具合があればご報告ください。 issue を作成する

インストール

IPA をサイドロードする。

署名のないアプリは、Safari や「ファイル」アプリからは直接インストールできません。サイドロードツールがご自身の Apple ID で署名してインストールします。

IPA をダウンロード

GitHub の最新リリースから sonora-ios.ipa を入手します。

デベロッパモードをオン

iOS 16 以降: 設定、プライバシーとセキュリティ、デベロッパモード。その後 iPhone を再起動します。

ツールでインストール

下のツールを選び、IPA を追加して Apple ID でサインインします。

AltStore

Mac または Windows PC に AltServer を入れ、iPhone の AltStore で IPA を開きます。同じ Wi-Fi 上にパソコンがあれば、バックグラウンドで自動的に更新されます。

altstore.io

SideStore

AltStore と同様ですが、更新は iPhone 上だけで行えます。初回設定のあとはパソコンが要りません。

sidestore.io

Sideloadly

Windows / macOS 用のデスクトップツール。iPhone を接続して IPA をドラッグし、Apple ID を入力して Start をクリックします。

sideloadly.io

TrollStore

期限なしで永続的にインストールできますが、特定の iOS バージョンでのみ使えます。

インストールのあとで

  • 設定、一般、VPN とデバイス管理を開き、ご自身の Apple ID のプロファイルを信頼します。その後 Sonora を開きます。
  • 無料の Apple ID では同時に 3 つまでで、更新しないと 7 日で期限切れになります。AltStore と SideStore は自動で更新します。Apple の有料デベロッパプログラムなら 1 年になります。
  • 更新は、新しい IPA を上書きインストールします。先にアプリを削除すると、中の音楽も消えるので避けてください。
  • Sonora はこれらのツールとは無関係で、承認も受けていません。

あなたの音楽

iPhone で音楽を追加する。

Android とは違う点です。iOS のアプリは自分専用のフォルダしか読み取れないため、Sonora はアプリ内の Documents/Music から再生します。先にファイルをそこへ入れてください。何もアップロードされません。

A

ファイルアプリで

パソコン不要です。まず Sonora を一度開いてフォルダを作らせます。ファイルアプリで、ブラウズ、このiPhone内、Sonora、Music と進み、曲をコピーします。その後 Sonora の曲リストを下に引っ張るか、設定の「今すぐ同期」をタップします。

B

Mac の Finder で

iPhone を接続して Finder で選択します。ファイルタブを開いて Sonora を展開し、音楽を Music フォルダにドラッグします。その後 Sonora で「今すぐ同期」を実行します。

C

アプリ内から

オンボーディング、設定、空のライブラリ画面で「音楽を追加」をタップします。音声ファイルを選ぶと、Sonora が Music フォルダにコピーします。すぐに表示されなければ「今すぐ同期」を実行してください。

知っておくと便利

ヒントと制限。

フォルダはどう整理すればいい?

Music/アーティスト/アルバム/曲.mp3 がおすすめです。ファイルにアーティストやアルバムのタグがない場合は、これらのフォルダ名が使われます。

どの形式が使える?

MP3、M4A/AAC、FLAC、WAV が確実で、「音楽を追加」の選択画面もこれらのみ表示します。Opus、OGG、WMA などは iOS のバージョンによります。

歌詞は?

曲と同じ名前の .lrc または .txt ファイルを曲の隣に置きます。同期時に Sonora が見つけます。

曲を削除するには?

ファイルアプリで削除してから、「今すぐ同期」を実行します。

音楽はどこに保存される?

iPhone の中の Sonora 内です。容量を使い、アプリを削除すると一緒に消えます。デバイスのバックアップには標準で含まれます。

Android と比べて足りないものは?

イコライザーとピッチ調整はありません（速度プリセットは使えます）。ホーム画面ウィジェット、CarPlay、「+1 分」「タイマー終了」ボタン、アプリ内アップデートもありません。スリープタイマー自体は使えます。ロック画面とコントロールセンターでの操作とバックグラウンド再生は動作しますが、シミュレーターでしか確認していません。

質問や不具合は?

iOS 版は新しいので、きちんと動くようにしたいと考えています。状況を教えてください。
